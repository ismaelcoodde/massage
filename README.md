# Aplicación web para un negocio de masajes

Proyecto de portfolio para aprender y demostrar el desarrollo de una aplicación web completa para la gestión de servicios y reservas de un negocio de masajes.

## Estado del proyecto

El proyecto se encuentra en su fase inicial de preparación.

Actualmente se está configurando la documentación, el control de versiones y la estructura base antes de comenzar el desarrollo de la aplicación.

## Objetivo

La aplicación permitirá, progresivamente, consultar servicios de masajes, comprobar disponibilidad, realizar reservas y gestionar pagos.

También se desarrollará una zona privada de administración para gestionar servicios, horarios y reservas.

## Tecnologías previstas

### Frontend

- React
- Vite
- JavaScript
- Tailwind CSS

### Backend

- Python
- Flask
- API REST

### Base de datos

- PostgreSQL

### Pagos

- Stripe Checkout
- Stripe Webhooks

### Infraestructura

- Docker
- Coolify
- VPS de Hetzner
- HTTPS y dominio propio

## Desarrollo

El proyecto se construirá progresivamente con fines educativos, aplicando buenas prácticas de arquitectura, seguridad, control de versiones y despliegue.
